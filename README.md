# models

neozp's support for database models generated by [sqlc](https://sqlc.dev):
enums, and the labels of tables, columns and enum values, generated through
[genx](https://github.com/epistemer/genx).

**Not started.** The repository holds what was known before the work began:

- [docs/brief.md](docs/brief.md): what the package is for, what is proven,
  and the questions still open.
- [docs/spikes/s4](docs/spikes/s4/README.md): the spike that showed sqlc's
  output can drive trivial generators.
- [docs/status.md](docs/status.md): the log of working sessions.

Part of neozp, alongside [cfgx](https://github.com/epistemer/cfgx),
[i18n](https://github.com/epistemer/i18n) and
[genx](https://github.com/epistemer/genx). License: [MIT](LICENSE).
